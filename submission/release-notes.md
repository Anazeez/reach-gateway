# Reach Gateway 0.1.0

Initial owner-private release of Reach the G.

- Retrieves normalized public Web, X, Reddit, RSS, and YouTube evidence.
- Retrieves available public YouTube captions.
- Reports evidence-channel health and provenance.
- Uses Cloudflare Access OAuth for exact-owner authentication.
- Keeps discovery in ChatGPT or Codex and uses no paid search API.
- Provides no write, private-account, cookie, token, or arbitrary-user access.

This release is distributed through the owner's personal plugin catalog and the registered private app identity. It is intentionally not submitted as a public multi-user directory listing.
